# SeasonX 品牌与视觉风格

> 后续改 logo、favicon、Header 或任何品牌图形时，先读本文，再动手。  
> 目标：在迭代中保持同一套气质，而不是每次重造风格。

---

## 1. 品牌一句话

| 项 | 内容 |
|----|------|
| 名称 | **SeasonX** |
| 域名 | seasonx.life |
| 定位 | 个人博客 · 技术、思考与生活 |
| 气质 | 书卷、克制、偏暖、编辑感；不科技霓虹、不插画满铺 |

灵感基底：Kami 系「羊皮纸 + 单一墨蓝 + 衬线正文」。  
图形识别：**3D CGI 狐狸头像**（暖橙毛皮、琥珀色眼睛），而非字母标或单线稿。

---

## 2. 设计关键词

用这些词做取舍；冲突时优先靠前的词：

1. **Character mascot（角色形象）** — Pixar / Zootopia 气质的 3D 狐狸，细毛皮、大眼睛、温和微笑  
2. **Editorial UI（编辑/刊名界面）** — 页面仍安静、可长期看；吉祥物只出现在标位，不铺满插画  
3. **Warm parchment（暖纸）** — 页面底是暖灰米色，不是纯白冷灰  
4. **Ink blue UI（界面单色强调）** — 链接、标题强调仍是墨蓝一系；狐狸本身用橙/奶白/琥珀  
5. **Avatar lockup（头像组合）** — Header 主标为正圆裁切头像，favicon 为圆角方

避免：

- 回到墨蓝单线稿、字母 S 标  
- 荧光、渐变紫蓝、科技电路图形  
- 无意义的几何装饰环绕 logo  
- 张嘴露齿、尖牙、夸张表情包画风  
- 把狐狸涂成第二套界面主色（按钮、链接仍用墨蓝）

## 3. 色板

与 `src/styles/global.css` 中 token 一致；改色先改 CSS 变量，再同步图形资产。

### 3.1 品牌与表面

| Token | Hex | 用途 |
|-------|-----|------|
| `--brand` | `#1b365d` | **界面主色**：链接、强调（狐狸图形除外） |
| `--brand-light` | `#2d5a8a` | hover / 次级强调 |
| `--brand-tint` | `#eef2f7` | 浅蓝底（标签、hover 圆） |
| `--tag-bg` | `#e4ecf5` | 标签底 |
| `--parchment` | `#f5f4ed` | 页面主底 |
| `--ivory` | `#faf9f5` | 抬升表面 |
| `--warm-sand` | `#e8e6dc` | 交互底、边框近色 |
| `--deep-dark` / `--near-black` | `#141413` | 主文字（暖黑，非纯黑） |

### 3.2 文字层级（暖灰）

| Token | Hex | 用途 |
|-------|-----|------|
| `--near-black` | `#141413` | 标题、正文主色 |
| `--dark-warm` | `#3d3d3a` | 次级正文 |
| `--olive` | `#504e49` | 弱化说明 |
| `--stone` | `#6b6a64` | meta、图标默认 |

### 3.3 Logo 用色规则

| 场景 | 狐狸 | 背景 |
|------|------|------|
| Header | 3D 正面头像，正圆裁切 | 图内暖桃橙底，叠在羊皮纸上 |
| favicon / 桌面图标 | 同源头像微裁 | 圆角方，保留桃橙底 |
| 关于页大图 | 坐姿全身 | 桃橙底铺满卡片上沿 |
| 界面强调色 | 不用狐狸橙 | 仍用 `--brand` 墨蓝 |

**原则：狐狸是唯一允许多色的图形；页面 UI 仍只有一系墨蓝。**

## 4. 字体

| 角色 | 字体 | 说明 |
|------|------|------|
| 正文 / UI | Noto Serif SC（回退 Source Han Serif SC / Songti / Georgia） | 全书卷感，不是无衬线产品站 |
| 代码 | JetBrains Mono 等 | 仅 code |
| 字标「SeasonX」 | 继承 Header 字重：`font-medium` + `tracking-tight` | 与狐狸并排，不另造花体 |

Logo 图形内**不出现文字**（字标在图形外用系统/站点字体排）。  
AI 出图若带字，落库前去掉文字，字标用代码排。

## 5. Logo 系统

### 5.1 主题

- **主体**：狐狸（Fox）  
- **画法**：3D CGI 角色肖像，细毛皮、琥珀色眼睛、闭合微笑  
- **构图**：暖桃橙纯色底；Header 正圆裁切，favicon 圆角方  
- **情绪**：友善、机敏、略电影感，仍克制（不张嘴、不搞怪）  

### 5.2 变体与文件

| 变体 | 文件 | 用途 | 选用理由 |
|------|------|------|----------|
| **正面头像（主标）** | `public/logo-fox.jpg` | Header、默认品牌图 | 对称、小尺寸仍可辨脸 |
| 侧面头像 | `public/logo-fox-profile.jpg` | 专题、横版组合 | 更优雅、叙事感 |
| 坐姿全身 | `public/logo-fox-sitting.jpg` | 关于页、空状态、品牌故事 | 完整、尾巴识别强 |
| favicon | `public/favicon.svg`、`favicon-32.png` | 浏览器标签 | 圆角方 + 同源头像 |
| 触控图标 | `public/apple-touch-icon.png` | iOS 主屏 | 圆角方 + 正面狐狸 |

接入位置：

- Header：`src/components/Header.astro`（`/logo-fox.jpg` 正圆 + 文案 SeasonX）  
- 站点图标：`src/components/BaseHead.astro`

### 5.3 形态规范

**主标（Header）**

- 图形：正面 3D 狐狸头像 JPEG，CSS `rounded-full` 裁成正圆  
- 尺寸：约 `36×36` CSS 像素（`h-9 w-9`），可随 header 微调 32–40  
- 与字距：`gap-2` 量级，图形在左、字标在右  
- Hover：字标跟站点 accent；头像保持原色，勿加滤镜/降透明度  

**Favicon**

- 画布 `32×32`，圆角约 `rx=6`  
- 同源正面头像，略向内裁，保证 16px 仍能看出耳 + 眼  
- 保留桃橙底，不要换成羊皮纸或墨蓝线稿  

**Lockup（组合标）**

```
[ 圆形狐狸头像 ]  SeasonX
```

- 不写 `.life` 进默认 lockup（域名出现在页脚/关于即可）  
- 不把 SeasonX 画进图片；字用 HTML/CSS  

### 5.4 导出与制作约定

| 项 | 约定 |
|----|------|
| 主交付 | JPEG 头像/坐姿（暖桃橙底），约 384–640px 边长、质量 ~86 |
| favicon | 32px 圆角 PNG + SVG 内嵌同源图 |
| 源概念图 | 正面/侧面/坐姿同一只狐狸，无字、无水印 |
| 禁止 | 混用旧单线稿；把 3D 狐去色成墨蓝；未压缩的 1MB+ PNG 进 Header |

## 6. 与页面视觉的关系

Logo 不是孤立贴纸，必须像从站点里长出来：

| 页面元素 | 与 logo 的对齐 |
|----------|----------------|
| 背景 | 羊皮纸暖色；头像自带桃橙底，正圆裁切后叠上去 |
| 分割线 | 虚线 `section-rule`，logo 勿用实线粗框抢戏 |
| 强调色 | UI 只有墨蓝一系；狐狸橙不进入按钮/链接 |
| 圆角 | Header 正圆；favicon 轻圆角方 |
| 阴影 | 页面用极轻 shadow；**头像本身不加投影** |
| 动效 | 至多文字颜色过渡；不要弹跳、旋转吉祥物 |

## 7. 使用场景速查

| 场景 | 用什么 | 注意 |
|------|--------|------|
| 顶栏 | 正面圆头像 + SeasonX | 固定主标，勿轮换坐姿 |
| 浏览器图标 | favicon（同源头像） | 小尺寸以耳 + 眼为先 |
| OG / 分享图 | 可选正面或侧面 + 标题排版 | 大图可留白，勿拉伸变形 |
| 关于页 / 品牌故事 | 坐姿 | 可铺满卡片展示毛皮 |
| 深色模式（若将来做） | 先定纸感是否保留；头像可保持原色 | 改前更新本文色表 |
| 打印 / 单色 | 可转灰度头像 | 勿改回单线稿除非品牌重做 |

## 8. 验收清单（改完必过）

- [ ] 狐狸是 3D CGI 角色（橙毛皮 + 奶白吻/胸 + 琥珀眼），三变体同一只  
- [ ] Header 为正圆头像，不透明、不加滤镜  
- [ ] favicon 圆角方，16px 仍能看出耳 + 眼  
- [ ] 仍是狐狸，不是猫/狼/抽象一团  
- [ ] Header 组合：图 +「SeasonX」对齐、不拥挤  
- [ ] 与 `--parchment` 页面并置不发灰、不发冷  
- [ ] 无字、无水印、无多余英文 slogan 进图  
- [ ] 界面链接/强调仍是墨蓝，未把狐狸橙做成第二套 UI 色  

---

## 9. 明确不要的方向（反例）

| 反例 | 原因 |
|------|------|
| 墨蓝单线狐狸 | 已从线稿演进到 3D 角色标，勿回退除非品牌重做 |
| 字母 S 取代狐狸 | 已从字母标演进到动物标，勿回退除非品牌重做 |
| 把狐狸橙做成按钮/链接色 | 破坏「UI 单色墨蓝」 |
| 张嘴露齿、表情包式五官 | 偏离克制的角色气质 |
| 科技电路、火箭、终端 prompt 图形 | 博客有技术向，但品牌不是 SaaS 产品标 |
| 多姿态同时塞进 Header | 主标只保留正面圆头像 |
